# 목록 unit — `npm test` 가 돌린다.
#
# 플래그(package.json 의 "test"):
#   --conditions=react-server --import tsx --import ./scripts/test-template-bootstrap.ts --test
#   - react-server 조건: `server-only` 를 불러오는 모듈을 그대로 시험할 수 있다.
#     대신 이 조건에서는 react-dom/server 가 스스로 막힌다 — 컴포넌트를 렌더해 보는
#     시험은 components.txt 에 적는다.
#   - 템플릿 부트스트랩: .env.local 에서 xlsx 양식 경로 여섯 개만 골라 넣는다.
#     DATABASE_URL 은 넣지 않는다 — 이 목록의 시험은 DB 에 닿을 길이 없어야 한다.
#     DB 에 붙는 시험은 db.txt 에 적는다.
#
# 적는 법(네 목록 공통):
#   - 한 줄에 한 경로. 저장소 뿌리 기준 상대경로, 구분자는 슬래시, 대소문자까지 정확히.
#   - `#` 로 시작하는 줄과 빈 줄은 건너뛴다.
#   - `*` 가 든 줄은 패턴이다 — node --test 가 직접 펼친다. App Router 의 `[id]` 같은
#     폴더를 그대로 적으면 node 가 글롭 문자클래스로 읽어 `tests 0` 으로 조용히
#     지나간다. 그 칸은 `*` 로 적는다.
#   - 없는 파일, 아무것도 가리키지 않는 패턴, 같은 줄 두 번이 있으면
#     scripts/run-test-list.mjs 가 돌기 전에 멈춘다.
#   - 새 *.test.ts(x) 는 네 목록 가운데 하나에 반드시 적는다. 빠지면
#     scripts/test-lists/test-list-registration.test.ts 가 `npm test` 에서 실패한다.
#   - node --test 는 받은 파일을 이름순으로 정렬해 돈다 — 줄 순서는 실행 순서가 아니다.
