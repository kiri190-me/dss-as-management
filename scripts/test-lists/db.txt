# 목록 db — `npm run test:db` 가 돌린다.
# 먼저 pretest:db 가 안전 시험(db-safety.txt)을 돌리고 시험 DB 를 준비·마이그레이트한다.
#
# 플래그(package.json 의 "test:db"):
#   --require ./scripts/node-windows-test-preload.cjs --conditions=react-server --import tsx
#   --import ./scripts/test-db-bootstrap.ts --test --test-concurrency=1
#   - DB 부트스트랩: scripts/load-test-env.ts 가 DATABASE_URL 을 .env.test.local 의 시험 DB
#     로 바꿔 끼운다. 개발 DB 와 같거나 이름이 _test 로 끝나지 않으면 거기서 멈춘다.
#   - --test-concurrency=1: 모든 파일이 한 시험 DB 를 함께 쓰므로 한 번에 한 파일씩 돈다.
#   - react-server 조건: unit.txt 와 같다(`server-only` 모듈을 그대로 부른다).
#   - node-windows-test-preload.cjs: db-safety.txt 머리를 볼 것.
#
